📧 Gmail IMAP Tool

1. Kích hoạt bán tự động

Nhập Gmail rồi bấm nút bên dưới. Cửa sổ đăng nhập Google sẽ mở ra — bạn tự đăng nhập (mật khẩu + 2FA). Khi tới trang App Password, tạo 1 cái (nhập tên bất kỳ → Create); tool sẽ tự bắt mã 16 ký tự và lưu lại.

Proxy chỉ dùng khi đọc mail qua IMAP; cửa sổ đăng nhập Google vẫn dùng mạng hiện tại.

2. Hoặc nhập tay App Password

Nếu bạn đã có sẵn App Password (dãy 16 ký tự), lưu account và proxy trực tiếp tại đây.

Khi cập nhật account đã có: để trống App Password để giữ mật khẩu cũ; để trống proxy để kết nối trực tiếp.
